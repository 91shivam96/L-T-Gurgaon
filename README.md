# L&T Sector 86 Gurgaon - Premium Residential Project Website

A modern, responsive single-page website for L&T  Sector 86 Gurgaon, a premium residential project in Sector 86, New Gurugram by L&T Realty.

## 🏠 Project Overview

This website showcases the L&T Sector 86 Gurgaon residential project, featuring:
- Premium 3 & 4 BHK residences
- Modern amenities and lifestyle facilities
- Excellent connectivity to key destinations
- Professional design with blue & white theme
- Mobile-responsive layout
- SEO-optimized structure

## ✨ Features

- **Premium Design**: Clean, professional blue & white color scheme
- **Responsive Layout**: Works perfectly on desktop, tablet, and mobile devices
- **Interactive Elements**:
  - Animated connectivity tabs (Hospitals, Education, Transports, Malls)
  - Floor plan cards with blurred images and configuration options
  - Gallery with hover effects
  - Popup enquiry form with auto-open
- **Lead Collection**: Form integration with FormSubmit.co
- **WhatsApp Integration**: Direct WhatsApp messaging
- **SEO Optimized**:
  - Optimized meta tags (title, description, keywords)
  - Structured data (JSON-LD) for rich snippets
  - Canonical URL
  - Open Graph & Twitter Card tags
  - Favicon configured
- **Fast Loading**: Optimized CSS and JavaScript
- **Accessibility**: Semantic HTML structure

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript (Vanilla)**: Interactive functionality
- **Google Fonts**: Inter font family
- **FormSubmit.co**: Form handling and email delivery

## 🚀 How to Use

### Local Development

1. **Clone or download the repository**
2. **Open `index.html`** in any web browser
3. No build process or server required - it's a static website

### Deployment

You can deploy this website to any static hosting service:
- **GitHub Pages**: Free hosting
- **Netlify**: Drag & drop deployment
- **Vercel**: Easy deployment
- **Any web hosting**: Upload files to public_html folder

## 🎨 Customization

### Changing Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --primary: #0066CC;      /* Main blue color */
    --primary-dark: #004499;  /* Darker blue */
    --primary-light: #4A90E2; /* Lighter blue */
    --secondary: #1A1A2E;     /* Dark text color */
    /* ... more variables */
}
```
